Evidence to Demand Letter

A modular architecture for converting unstructured case documents into structured evidence, contextual retrieval, AI-assisted analysis, and review-ready demand letter drafts.

Architecture

Layered system design.

The platform separates user-facing workflows, APIs, data services, AI orchestration, storage, and infrastructure so each layer can evolve independently.

Frontend
Next.js Web Application Case management, document upload, review interface, evidence viewer, demand letter editor, and exports.
↓
API
FastAPI Application Services Authentication, case APIs, document processing, workflow orchestration, retrieval, and generation services.
↓
Data
PostgreSQL + pgvector Structured case records, extracted entities, document metadata, embeddings, and semantic retrieval indexes.
↓
AI
RAG + LangGraph Multi-Agent Workflow Extraction, timeline construction, evidence retrieval, analysis, drafting, validation, and citation grounding.
↓
Infrastructure
AWS + Docker + Terraform + CI/CD Object storage, containers, deployment automation, infrastructure as code, observability, and secure delivery.
Document Workflow

From raw documents to structured evidence.

01

Ingestion

Upload case PDFs and DOCX files. Store originals and metadata in object storage for downstream processing.

02

Parsing & OCR

Extract text from digital documents and provide an OCR path for scanned or image-based material.

03

Structured Extraction

Identify patients, providers, dates, diagnoses, treatments, expenses, and other relevant case entities.

04

Timeline Generation

Convert extracted events into a chronological representation of treatment and case development.

05

Semantic Indexing

Chunk evidence and generate embeddings for semantic retrieval through PostgreSQL and pgvector.

06

Evidence Grounding

Retrieve source passages relevant to each AI-generated claim so outputs remain connected to case evidence.

Multi-Agent AI

Specialized agents for controlled generation.

The AI workflow is designed as a sequence of specialized tasks rather than relying on a single unrestricted generation step.

Document Agent

Identifies document type, extracts relevant sections, and prepares content for downstream processing.

Medical Extraction Agent

Structures treatment history, diagnoses, procedures, providers, and medically relevant events.

Timeline Agent

Builds a chronological case timeline from extracted dates and treatment events.

Damages Agent

Organizes documented medical expenses and other supported damages information.

Research & Retrieval Agent

Retrieves relevant evidence from the indexed case materials and prepares context for generation.

Drafting Agent

Produces a structured demand letter draft using retrieved evidence and extracted case facts.
