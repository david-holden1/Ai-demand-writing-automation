# AI Demand Writing Automation

AI-powered legal document automation platform for evidence-backed demand letter generation using RAG and multi-agent AI workflows.

## Project Status

🚧 Currently under development.

## Planned Features

- Case management
- PDF/DOCX document upload
- AI document processing
- Medical information extraction
- Case timeline generation
- Medical expense extraction
- RAG-based document search
- Evidence-backed AI responses
- AI demand letter generation
- Human review and editing
- PDF/DOCX export
- Authentication and role-based access control
- Audit logging

## Technology Stack

- Next.js
- TypeScript
- Python
- FastAPI
- PostgreSQL
- pgvector
- LangGraph
- OpenAI / Anthropic
- Docker
- AWS
- Terraform
- GitHub Actions
